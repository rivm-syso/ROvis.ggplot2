# ROvis.ggplot2: Create data visualisations in Rijksoverheid style using ggplot2

A tool to uniformly visualise graphs in 'ggplot2' using standardized
Rijksoverheid (Dutch National Government) styling. Part of the ROvis
umbrella package.
